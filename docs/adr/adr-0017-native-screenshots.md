# ADR-0017：截图使用 macOS 原生捕获

- Status：accepted
- Kind：architecture
- Date：2026-10-24
- Supersedes：ADR-0001 的截图接管部分
- Implements：#317
- 相关：[ADR-0010](adr-0010-unified-file-area.md)

## 背景

旧版 Covio 修改 `com.apple.screencapture`。
旧版 Covio 重定向截图文件，隐藏系统缩略图，并显示顶部挂帘。
旧版 Covio 还提供夹子、卡片拖拽、音效和多组截图设置。

ADR-0010 已把截图入口放进统一文件区。
旧运行时仍然存在，用户还会看到旧截图界面。
因此，文件区与旧截图接管并存。

## 决策

1. macOS 截图只使用系统捕获。
2. Covio 不修改、不重定向、不隐藏系统截图界面。
3. Covio 监视系统当前截图目录。
4. Covio 把截图路径写入 `shelf.json`。
5. 「文件 → 截图」是唯一截图入口。
6. 删除顶部挂帘、晾衣线、夹子、旧截图卡片、拖拽和音效。
7. 删除截图接管、挂帘显示和截图音效设置。
8. 一级菜单栏入口与次级状态项使用 `CovioStatusIcon`。
9. 旧配置键继续序列化为 `false`，避免旧版重新开启接管。
10. 旧快照只做一次迁移恢复。恢复成功后立即删除快照。

## 后果

### 正面

- 用户保留 macOS 原生截图体验。
- Covio 不再长期拥有系统截图设置的所有权。
- 截图、工作区文件和传输只有一个入口。
- 旧配置仍可双向读取。
- 旧截图索引仍可显示。

### 负面

- Covio 不能控制系统截图保存位置。
- Covio 不能隐藏系统截图缩略图。
- 用户需要打开 Hub 才能操作截图索引。

### 风险

- 自定义截图目录可能变化。缓解：启动时重新读取系统设置。
- 旧版本可能留下偏好快照。缓解：启动时恢复一次并清除快照。
- 回退旧版可能重新开启接管。缓解：新版本始终写回三个兼容键为 `false`。

## 备选方案

### 保留截图接管并只删除挂帘

接管仍会修改系统设置。
系统截图流程仍由 Covio 控制。
这不满足原生截图目标。

### 复制截图到 Covio 目录

复制会占用双倍磁盘空间。
原文件与副本的删除语义会分叉。
不采用。

### 删除截图索引

用户会失去文件区里的截图历史。
旧 `shelf.json` 也无法继续使用。
不采用。
