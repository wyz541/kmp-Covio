# ADR-0022：默认开启实验性合盖黑屏

- Status：accepted
- Kind：architecture
- Date：2026-10-28
- Supersedes：ADR-0012 的默认关闭部分
- Implements：#398
- 相关：#203

## 背景

ADR-0012 把实验性合盖黑屏设为默认关闭。
该决策限制私有 API 的默认影响范围。
项目负责人现在要求新配置默认开启该能力。
已有配置中的显式开关值仍必须保持不变。

该能力仍是实验能力。
它只在合盖保持唤醒会话中运行。
它不使用 gamma、遮罩或隐藏窗口。

## 决策

1. `closedLidZeroBrightness` 的默认值为 `true`。
2. 新配置和缺少该键的旧配置得到 `true`。
3. 配置中存在显式 `false` 时，Covio 保留 `false`。
4. 清除配置后，默认值恢复为 `true`。
5. 只允许 helper 身份匹配、macOS 版本已验证且私有符号可用的环境写入零亮度。
6. 私有路径不可用或失败时，Covio 回退到公开合盖关屏路径。
7. 该默认值不自动创建合盖会话。用户开始合盖保持唤醒后，实验路径才可运行。
8. UI 继续显示“实验性”和“可能随 macOS 更新失效”。
9. 用户关闭开关后，Covio 立即恢复原亮度。
10. ADR-0012 的默认关闭决定由本 ADR 取代。ADR-0012 的其他安全约束继续有效。

## 后果

### 正面

- 新用户不增加一次显式开关操作。
- 合盖保持唤醒的默认显示行为与产品要求一致。
- 显式关闭、能力检测和失败回退仍然有效。

### 负面

- 更多用户会接触到私有 API。
- 私有 API 失效时，用户会更早看到失败或回退路径。
- 默认黑屏可能让用户误以为显示器已关闭。

### 风险

- 私有 API 随 macOS 更新失效。缓解：版本白名单、动态符号检查和公开路径回退。
- 亮度恢复失败。缓解：原子恢复记录、启动恢复、错误提示和手动关闭开关。
- 用户误以为系统自动合盖黑屏。缓解：文案说明只在合盖保持唤醒会话中运行。
- 外接屏被误写。缓解：外接屏存在或状态未知时禁止私有写入。

## 备选方案

### 备选 1：保持默认关闭

该方案保留 ADR-0012 的最小暴露范围。

未采纳。项目负责人明确要求默认开启。

### 备选 2：仅新配置默认开启

该方案不改变旧配置缺少该键时的行为。

未采纳。配置默认值应一致，避免同类配置产生不同显示行为。
