本文说明 Monitor 工作区的卡片设计。
本文列出卡片清单与每张卡片的成员。
本文只定义设计。展开交互尚未实现。

## 1. 结论

Monitor 工作区使用三段式卡片。
每张卡片按三个层级显示信息。

1. Primary Value 显示当前主数值。
2. Context Line 显示最近一段时间的趋势。
3. Expandable Detail 显示详细成员。

用户先看当前值。用户再看趋势。用户需要时再展开详情。
因此，卡片先回答“现在是多少”。
然后，卡片回答“最近怎么变化”。
最后，卡片回答“由哪些成员构成”。

## 2. 阅读层级

| 层级 | 用户问题 | 卡片内容 | 默认状态 |
| --- | --- | --- | --- |
| Primary Value 主数值锚点 | 现在是多少？ | 主数值、单位、环形读数和实时状态 | 始终显示 |
| Context Line 趋势线 | 最近如何变化？ | 最近 60 个采样点的 Sparkline | 始终显示 |
| Expandable Detail 可展开详情区 | 具体成员是什么？ | 标签、数值和采样信息 | 默认折叠 |

Primary Value 是卡片的视觉起点。
主数值使用大号文字和环形进度表示。
环形进度只表示比例。百分比仍以文字为准。

Context Line 是卡片的方向提示。
火花线（Sparkline）显示最近 60 个采样点。
火花线不显示坐标轴。火花线不替代精确数值。

Expandable Detail 是卡片的校验区。
详情区先显示常用成员。用户展开后看到其余成员。
详情区不增加新的取数来源。

## 3. 共享规则

### 3.1 卡片外壳

每张卡片使用相同外壳。

| 成员 | 规则 |
| --- | --- |
| 图标 | 使用卡片类型的 SF Symbol |
| 标题 | 使用设计合同的 `copy/monitor/title/*` 文案 |
| 状态胶囊 | 显示 `实时` |
| 强调色 | 使用设计合同的卡片类型颜色 |
| 边框 | 使用 1 点强调色边框 |
| 材质 | 使用玻璃表面和卡片圆角 |

卡片外壳不属于三个信息层级。
外壳帮助用户识别卡片类型。

### 3.2 采样与历史

| 项目 | 规则 |
| --- | --- |
| 采样条件 | 只在 Monitor 页可见时采样 |
| 采样容量 | 每张卡片保留最近 60 个采样点 |
| 接电源周期 | 1 秒 |
| 使用电池周期 | 5 秒 |
| 历史窗口 | 60 个采样点。实际时长取决于当前采样周期。 |
| 新点处理 | 历史满 60 点后删除最旧的点 |
| 页面离开 | 停止采样 |
| 返回页面 | 从空历史重新累积 |

趋势线不固定代表 60 秒。接电源时约为 60 秒。使用电池时约为 300 秒。
卡片详情必须显示当前采样周期。

### 3.3 数值格式

| 类型 | 格式 |
| --- | --- |
| 比例 | 四舍五入为整数百分比 |
| 字节 | 使用十进制单位 `B`、`KB`、`MB`、`GB`、`TB` |
| 速率 | 字节每秒，例如 `10.2 MB/s` |
| 负载 | 保留两位小数 |
| 时长 | 使用 `d`、`h`、`m`；小于 1 分钟显示 `<1m` |
| 缺失值 | 显示不可用，不显示 0 |

### 3.4 展开交互

第三段使用详情披露控件（Disclosure）。
默认状态为折叠。

| 操作 | 结果 |
| --- | --- |
| 点击详情区标题 | 展开或折叠当前卡片 |
| 点击展开控件 | 展开或折叠当前卡片 |
| 按 `Return` 或 `Space` | 展开或折叠当前卡片 |
| 展开 | 显示详情成员和采样信息 |
| 折叠 | 保留摘要成员 |

展开状态只影响当前卡片。
用户离开 Monitor 页后，卡片回到折叠状态。
展开动画使用 160 毫秒的缓出曲线。
系统打开减弱动态效果时，展开只改变透明度。

当前实现只显示摘要详情。
当前实现没有披露控件。
后续实现卡片展开时，按本节的规则执行。

### 3.5 详情成员

详情区分两组。

| 组 | 内容 | 默认状态 |
| --- | --- | --- |
| 摘要成员 | 用户最常用的 1 至 3 个成员 | 显示 |
| 扩展成员 | 卡片特有的补充成员 | 折叠 |
| 采样信息 | 采样时间、采样周期和历史样本数 | 折叠 |

采样信息适用于全部卡片。

| 标签 | 示例 | 数据来源 |
| --- | --- | --- |
| 采样时间 | `14:32:08` | `MonitorSnapshot.sampledAt` |
| 采样周期 | `1 秒` 或 `5 秒` | `MonitorCadence` |
| 历史样本 | `24/60` | `MonitorHistory` |

### 3.6 不可用状态

CPU、GPU、内存、磁盘和网络读取失败时，显示不可用卡片。
不可用卡片保留图标、标题和卡片外壳。
不可用卡片显示 `不可用`，并隐藏主数值、趋势线和详情成员。

电池数据为空时，隐藏电池卡片。
台式机通常没有内置电池，因此不显示电池卡片。

热状态与采样周期属于工作区状态行。
热状态与采样周期不放进单张指标卡片的 Primary Value。

### 3.7 布局

| 项目 | 规则 |
| --- | --- |
| 列数 | 默认 3 列 |
| 最小列宽 | 170 点 |
| 卡片间距 | 使用 `MacTheme.space3` |
| 卡片高度 | 折叠状态使用 `HubMetrics.monitorCardHeight` |
| 顺序 | CPU、GPU、内存、磁盘、网络、电池 |
| 电池卡片 | 只有存在电池数据时显示 |

### 3.8 无障碍

卡片使用一个组合无障碍元素。
VoiceOver 一次读出卡片标题、主数值、趋势摘要和详情。

环形读数与火花线是视觉装饰。
环形读数与火花线对 VoiceOver 隐藏。
详情文字提供可读数值。

展开控件必须是可聚焦按钮。
展开控件必须提供 `展开详情` 或 `折叠详情` 标签。
展开状态变化必须由辅助技术读出。

### 3.9 颜色

| 卡片 | 颜色来源 |
| --- | --- |
| CPU | `token/color/brand` |
| GPU | 应用强调色 |
| 内存 | `token/color/success-fill` |
| 磁盘 | `token/color/warning-fill` |
| 网络 | `token/color/error-text` |
| 电池 | `token/color/success-fill` |

颜色不单独表达状态。
状态必须同时显示文字。

## 4. 卡片清单

Monitor 支持六张卡片。

| 序号 | 卡片 | 主问题 | 显示条件 |
| --- | --- | --- | --- |
| 1 | CPU | 处理器当前有多忙？ | CPU 数据可用 |
| 2 | GPU | 图形处理器当前有多忙？ | GPU 数据可用 |
| 3 | 内存 | 内存当前使用了多少？ | 内存总量大于 0 |
| 4 | 磁盘 | 磁盘容量和读写活动如何？ | 容量数据可用 |
| 5 | 网络 | 当前接口的上下行速率是多少？ | 网络计数器可用 |
| 6 | 电池 | 电池电量和剩余时间是多少？ | 存在内置电池 |

## 5. 卡片成员设计

### 5.1 CPU

| 层级 | 成员 | 展示规则 |
| --- | --- | --- |
| Primary Value | CPU 使用率 | 环形读数加百分比。数据来自 `cpu.usage`。 |
| Context Line | CPU 历史 | 显示最近 60 个 `cpu.usage` 采样点。 |
| Context Line 辅助件 | 每核柱形 | 显示每核负载。当前实现最多显示前 16 个核心。 |
| Expandable Detail · 摘要 | 每核 | 显示每核平均使用率。 |
| Expandable Detail · 摘要 | 1 分钟负载 | 显示系统 1 分钟平均负载。 |
| Expandable Detail · 摘要 | 核心 | 显示逻辑核心数量。 |
| Expandable Detail · 扩展 | 运行时间 | 显示系统运行时间。数据来自 `cpu.uptime`。 |
| Expandable Detail · 扩展 | 逐核负载 | 逐项显示每核百分比。 |
| Expandable Detail · 扩展 | 采样信息 | 显示采样时间、采样周期和历史样本数。 |

CPU 不可用时显示不可用卡片。
CPU 卡片当前显示 3 个摘要成员。
CPU 卡片当前不显示运行时间和逐核数值列表。

### 5.2 GPU

| 层级 | 成员 | 展示规则 |
| --- | --- | --- |
| Primary Value | GPU 使用率 | 环形读数加百分比。数据来自 `gpu.usage`。 |
| Context Line | GPU 历史 | 显示最近 60 个 `gpu.usage` 采样点。 |
| Expandable Detail · 摘要 | 已用显存 | 显示当前 GPU 内存占用。 |
| Expandable Detail · 摘要 | 设备 | 显示 GPU 型号。 |
| Expandable Detail · 扩展 | 采样信息 | 显示采样时间、采样周期和历史样本数。 |

GPU 不可用时显示不可用卡片。
GPU 卡片没有额外的卡片专属扩展成员。

### 5.3 内存

| 层级 | 成员 | 展示规则 |
| --- | --- | --- |
| Primary Value | 内存使用率 | 使用 `memory.used / memory.total`。环形读数加百分比。 |
| Context Line | 内存历史 | 显示最近 60 个内存使用率采样点。 |
| Expandable Detail · 摘要 | 已用 | 显示当前内存占用量。 |
| Expandable Detail · 摘要 | 总量 | 显示物理内存总量。 |
| Expandable Detail · 摘要 | 交换 | 显示交换空间使用量。 |
| Expandable Detail · 扩展 | 压力 | 显示 `正常`、`警告` 或 `紧急`。 |
| Expandable Detail · 扩展 | 采样信息 | 显示采样时间、采样周期和历史样本数。 |

内存不可用或总量为 0 时显示不可用卡片。
当前详情数组包含压力成员。
当前视图只显示前 3 个成员，因此压力成员被隐藏。

### 5.4 磁盘

| 层级 | 成员 | 展示规则 |
| --- | --- | --- |
| Primary Value | 容量使用率 | 使用 `disk.used / disk.total`。环形读数加百分比。 |
| Context Line | 读写吞吐历史 | 显示最近 60 个 `disk.readRate + disk.writeRate` 采样点。 |
| Expandable Detail · 摘要 | 读取 | 显示当前读取速率。 |
| Expandable Detail · 摘要 | 写入 | 显示当前写入速率。 |
| Expandable Detail · 摘要 | 可用 | 显示可用容量。 |
| Expandable Detail · 扩展 | 已用容量 | 显示已用容量。 |
| Expandable Detail · 扩展 | 总容量 | 显示卷总容量。 |
| Expandable Detail · 扩展 | 采样信息 | 显示采样时间、采样周期和历史样本数。 |

磁盘不可用或总容量为 0 时显示不可用卡片。
趋势线表示读写吞吐量。
趋势线不表示容量历史。

### 5.5 网络

网络卡片使用双主数值锚点变体。
下行速率和上行速率组成 Primary Value。

| 层级 | 成员 | 展示规则 |
| --- | --- | --- |
| Primary Value | 下行 | 显示当前下载速率。使用向下箭头。 |
| Primary Value | 上行 | 显示当前上传速率。使用向上箭头。 |
| Context Line | 下行历史 | 显示最近 60 个下载速率采样点。 |
| Context Line | 上行历史 | 显示最近 60 个上传速率采样点。 |
| Expandable Detail · 摘要 | 接口 | 显示当前主要网络接口，例如 `en0`。 |
| Expandable Detail · 扩展 | 下行 | 显示展开时的精确下载速率。 |
| Expandable Detail · 扩展 | 上行 | 显示展开时的精确上传速率。 |
| Expandable Detail · 扩展 | 采样信息 | 显示采样时间、采样周期和历史样本数。 |

网络不可用时显示不可用卡片。
接口切换时，速率差值从新接口重新计算。

### 5.6 电池

| 层级 | 成员 | 展示规则 |
| --- | --- | --- |
| Primary Value | 电量 | 环形读数加百分比。数据来自 `battery.percent`。 |
| Context Line | 电量历史 | 显示最近 60 个电量采样点。 |
| Expandable Detail · 摘要 | 状态 | 显示 `充电中`、`使用电池`、`已充满`、`电源适配器` 或 `未知`。 |
| Expandable Detail · 摘要 | 剩余 | 显示预计剩余时间。无法计算时显示 `—`。 |
| Expandable Detail · 扩展 | 采样信息 | 显示采样时间、采样周期和历史样本数。 |

电池数据为空时隐藏卡片。
台式机通常不显示电池卡片。
电池卡片没有额外的卡片专属扩展成员。

## 6. 当前实现与目标设计

| 项目 | 当前实现 | 目标设计 |
| --- | --- | --- |
| Primary Value | 已实现环形读数 | 保持不变 |
| Context Line | 已实现 60 点火花线 | 保持不变 |
| 详情摘要 | 最多显示 3 行 | 按卡片显示 1 至 3 行 |
| 详情展开 | 未实现 | 使用披露控件展开扩展成员 |
| CPU 运行时间 | 已采集，未显示 | 在展开区显示 |
| CPU 逐核数值 | 已采集，只用柱形显示 | 在展开区显示逐核百分比 |
| 内存压力 | 已采集，当前被截断 | 在展开区显示 |
| 磁盘已用与总量 | 已采集，当前未显示 | 在展开区显示 |
| 采样信息 | 只在工作区状态行显示部分信息 | 在每张卡片的展开区显示 |
| 无障碍组合 | 已实现卡片组合标签 | 保持不变 |
| 无障碍展开控件 | 未实现 | 提供可聚焦按钮和状态标签 |

## 7. 验收检查

1. 卡片按 Primary Value、Context Line、Expandable Detail 的顺序排列。
2. 每张卡片的主数值使用文字和单位。
3. 每张卡片的趋势线最多保留 60 个采样点。
4. 每张卡片的摘要成员不超过 3 个。
5. 每张卡片能显示采样时间、采样周期和历史样本数。
6. 详情展开后显示卡片专属扩展成员。
7. CPU、GPU、内存、磁盘和网络缺失时显示不可用卡片。
8. 电池缺失时隐藏电池卡片。
9. 网络卡片同时显示下行和上行。
10. VoiceOver 不重复朗读装饰图形。
11. 展开控件支持键盘和辅助技术。
12. 页面离开后采样停止，卡片回到折叠状态。
