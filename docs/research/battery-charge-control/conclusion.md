# 结论与限制

## 1. 结论

完整 `20%` 到 `100%` 范围不能使用同一条安全路径实现。

macOS 27 的可用方案分为两段：

| 范围 | 可行路径 | 权限 | 结论 |
| --- | --- | --- | --- |
| `80%` 到 `100%` | `PowerUISmartChargeClient` 和原生 MCL | 无 root | 条件可做 |
| `20%` 到 `79%` | root 原生偏好或独立 powerd 策略 | root helper | 暂不产品化 |
| 旧系统充电键可用 | `CH0B`、`CH0C` | root helper | 条件可做，需单独矩阵 |
| 无安全写入路径 | 无 | 无 | 不支持 |

原生 MCL 是私有接口。
它不是 Apple 公开文档 API。
因此，“条件可做”表示需要产品接受私有接口风险。

## 2. 旁路供电

本机观察到真实的系统旁路状态。

| 证据 | 观察 |
| --- | --- |
| `PowerUISmartChargeClient.status` | `BypassEngaged` |
| `pmset -g battlimit` | `chargeSocLimitDrain=1` |
| `pmset -g battlimit` | `chargeSocLimitIsEOC=1` |
| `ioreg` | `ExternalConnected=Yes` |
| `ioreg` | `IsCharging=No` |
| `ioreg` | `BatteryPower=0` |

因此，原生 MCL 可以把电池保持在 `80%`。
适配器继续供电。
电池电流为 `0`。
系统状态明确显示 `BypassEngaged`。

## 3. 5% 回差

原生 MCL 不提供 `5%` 回差参数。
回差由固件和系统策略决定。
本机在 `79%` 且上限为 `80%` 时没有再充电。
该观察支持“不会立即补 1%”。
但该行为不是稳定 API。
因此，不能承诺所有机型都满足 `5%` 回差。

如果产品强制要求 `5%` 回差，首期只能：
1. 接受固件策略。
2. 改为旧 SMC 路径。
3. 推迟到独立 root 策略通过验证。

## 4. 系统策略优先级

原生 MCL 是系统设置的一部分。
Covio 设置原生 MCL 会改写系统充电上限。
因此，产品需要明确以下行为：

| 场景 | 推荐行为 |
| --- | --- |
| 用户首次设置 | 保存原系统 MCL 状态和值 |
| 用户修改上限 | 更新 Covio 值并同步原生 MCL |
| 用户在系统设置中修改 | 读取到外部变更；不静默覆盖 |
| 用户恢复默认 | 恢复原系统 MCL 状态和值 |
| Apple 校准周期启动 | 显示系统临时接管，不误报错误 |
| Covio 退出 | 按产品设置保留或恢复 |

## 5. 决策表

| 决策 | 选择 | 原因 |
| --- | --- | --- |
| 首期是否支持 `20%` 到 `100%` | 否 | 安全路径只覆盖 `80%` 到 `100%` |
| 首期是否使用原生 MCL | 条件采用 | 无 root，旁路可验证，私有接口 |
| 首期是否支持 `20%` 到 `79%` | 否 | 需要 root 私有策略，未验证 |
| 是否写旧 SMC 键 | macOS 27 不写 | 键不存在或 entitlement 阻止 |
| 是否写新 SMC 键 | 否 | 第三方无 entitlement |
| 是否写 root 原生偏好 | 暂不 | 需要新 helper 和校准规避 |
| 是否把停止充电称为旁路 | 否 | 必须读取旁路证据 |
| 是否保留 5% 回差承诺 | 否 | 原生接口不提供该参数 |
| 是否保留用户原策略 | 是 | 避免破坏系统设置 |

## 6. 推荐

建议把 Feature #137 的范围改为两阶段。

### 第一阶段

1. 仅支持 `80%` 到 `100%`。
2. 只使用原生 MCL。
3. 不需要新的特权 helper。
4. 显示系统是否支持、当前上限和旁路状态。
5. 保存并恢复用户原有设置。
6. 外部修改和系统校准时显示原因。

### 第二阶段

只有以下条件全部满足后，再研究 `20%` 到 `79%`：

1. 产品接受私有 root 策略。
2. 独立 spike 证明策略不会被校准周期覆盖。
3. 睡眠、唤醒、重启和退出恢复全部通过。
4. Intel、Apple Silicon 和无电池设备矩阵完成。
5. 安全团队接受恢复失败风险。

## 7. 未决项

| 项目 | 现状 | 下一步 |
| --- | --- | --- |
| `20%` 到 `79%` | 技术证据存在，成熟度低 | 单独 spike |
| Apple 校准周期 | 原生状态可观察到，写入覆盖未验证 | 真机周期测试 |
| 5% 回差 | 固件决定 | 产品接受或改用 SMC |
| Intel MCL | 未验证 | 找 Intel Mac |
| 无电池设备 | 未真机验证 | 找台式机 |
| App Store 审核 | 未验证 | 发布策略评审 |
| macOS 版本矩阵 | 部分证据 | 补 macOS 26.x 和 27.x |
