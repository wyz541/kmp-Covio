# 跨设备控制验证计划

## 1. 目标

验证 Windows 可以发现、配对、连接和读取 macOS 状态。验证写能力的授权、范围、恢复和失败处理。

## 2. 环境

| 项目 | 要求 |
| --- | --- |
| Windows | Windows 11 24H2 或更高 |
| Windows 账户 | 标准用户 |
| macOS | macOS 26 或更高 |
| macOS 账户 | 有管理员权限的本地账户 |
| 网络 | 同一局域网和同一 Tailscale tailnet |
| Windows 客户端 | 最新内测构建 |
| macOS 主机 | 最新内测构建 |

## 4. 安全测试

1. 在 mDNS TXT 记录中查找秘密。
2. 修改配对 URI 的设备 ID。
3. 替换证书并保留原设备名。
4. 重放已成功的写请求。
5. 发送超出范围的亮度和风扇值。
6. 在未授权设备上调用每个写方法。
7. 撤销设备后继续发送请求。
8. 检查日志是否包含私钥或配对秘密。

## 5. 性能阈值

| 项目 | 阈值 |
| --- | --- |
| 局域网发现 | 5 秒 |
| 在线状态更新 | 30 秒 |
| 局域网建连 | 2 秒 |
| 局域网控制往返 | 300 毫秒 |
| Tailscale 控制往返 | 1 秒 |
| 撤销生效 | 30 秒 |

## 6. 风险

| 风险 | 影响 | 降低办法 |
| --- | --- | --- |
| mDNS 被阻断 | 设备不出现 | 手动地址 |
| Tailscale 未安装 | 公网不可用 | 显示安装指引 |
| 证书错误 | 无法连接 | 重新配对流程 |
| 写操作失败 | 设备状态不确定 | 重新读取状态 |
| 风扇失控 | 硬件风险 | 租约和恢复测试 |
| 远程睡眠 | 数据丢失 | 授权和确认策略 |
| 请求重放 | 重复操作 | 幂等键和过期时间 |

## 7. 清理

1. 撤销测试设备。
2. 删除双方测试证书。
3. 删除测试配置。
4. 移除 Tailscale 测试设备。
5. 恢复原始电源、亮度和风扇策略。
6. 记录清理时间和结果。
