## 验证目标

1. 预览显示原名、目标名、证据、风险和稳定错误码。
2. 用户只应用选中的就绪条目。
3. 重命名前复核文件身份、大小和修改时间。
4. 同名目标不被覆盖。
5. 撤销记录在写入前落盘。
6. 撤销可以恢复原名称。
7. 撤销不覆盖新出现的原路径。
8. 部分失败保留成功条目和逐条结果。
9. 符号链接、跨目录和扩展名变化被拒绝。

## 实现要点

1. `AutoNamingRuntime` 串行分析文件并生成预览。
2. `AutoNamingPreviewView` 提供选择、应用、关闭和撤销动作。
3. 文件身份使用设备号、inode、大小和修改时间。
4. 原子重命名使用 `renameatx_np` 与 `RENAME_EXCL`。
5. 撤销计划在第一次改名之前写入 `rename-undo/`。
6. 撤销按相反顺序执行。
7. 原路径或目标路径发生变化时，撤销拒绝该条。
8. 每一条失败都有稳定错误码。

```bash
  -project macosApp/Covio.xcodeproj \

  -only-testing:CovioTests/AutoNamingRuntimeTests \
  test
```

| 测试组 | 用例数 | 结果 |
| --- | --- | --- |
| `FileRenameServiceTests` | 8 | 通过 |
| `AutoNamingRuntimeTests` | 9 | 通过 |

覆盖场景：

1. 同目录改名与撤销恢复。
2. 目标已存在时两个文件内容都不变。
3. 预览后文件变化时拒绝改名。
4. 撤销计划写入失败时不改名。
5. 撤销拒绝覆盖新出现的原路径。
6. 符号链接被拒绝。
7. 跨目录目标被拒绝。
8. 扩展名变化被拒绝。
9. 部分成功后可以撤销成功条目。
10. 批量预览为重复目标追加编号。
11. 预览后新建同名目标时返回 `targetExists`。
12. 低可信结果进入阻止状态。
13. 扫描 PDF 显示扫描件风险。
14. 空选择不执行改名。
15. Files 页尺寸的预览可以生成 PNG。
16. 取消分析后不留下预览条目。
17. 无 OCR 图片在 VLM 可信度达到门槛时可以进入预览。

## UI 与可访问性

1. 每条结果有一个复选框。
2. 复选框有明确标签和原文件名值。
3. 原名与目标名分别有 VoiceOver 标签。
4. 应用、撤销和关闭使用原生按钮。
5. 阻止、失败和撤销状态显示文字，不只依赖颜色。
6. 风险使用文字标签。
7. 技术证据和稳定错误码保留原文。
