# 结论与限制

> 本文件承载结论摘要、决策因素、决策表、不采用方案、限制和未决项。

## 1. 结论摘要

macOS 上多数硬件指标可以无 root、无私有接口读取。

能力分三档。

| 档 | 指标 | 权限 | 第一版 |
| --- | --- | --- | --- |
| 直接可读 | CPU 使用率、内存、磁盘容量与吞吐、网络吞吐、电池、合盖、热压力 | 无 | 做 |
| 需要授权 | Wi-Fi 名称与 BSSID、蓝牙设备与电量 | 位置服务、蓝牙 | 部分做 |
| 需要私有接口 | CPU 频率、温度、风扇、整机功耗 | 未定 | 留接口，不实现 |

Windows 本版没有结论。

## 2. 决策因素

### 2.1 主要因素

接口的公开性是主要约束。

1. 公开接口能覆盖用户最常看的指标。
2. 私有接口有上架风险，且随系统升级失效。
3. `IOReport` 在本机已经不可解析。这是最直接的证据。

### 2.2 次要因素

| 因素 | 内容 |
| --- | --- |
| 权限成本 | 位置服务与蓝牙授权要弹窗。用户拒绝后指标缺失。 |
| 硬件差异 | 传感器键按 SoC 变化。台式机没有电池与合盖。 |
| 采样成本 | 高频轮询影响续航。笔记本电池供电时要降频。 |
| 命令开销 | `pmset` 与 `system_profiler` 要起进程，只能低频用。 |

### 2.3 证据链

```text
研究问题：能监听哪些硬件信息，来源是什么
  -> 来源：E-02、E-03、E-15、E-17
  -> 观察：Mach 调用、sysctl、IOKit 服务与公开框架覆盖多数指标
  -> 推论：第一版不需要私有接口
  -> 来源：E-05、E-09
  -> 观察：IOReport 在 macOS 27 上不在磁盘，符号不可解析
  -> 推论：CPU 频率与整机功耗不能进第一版
  -> 决策：第一版做直接可读档，私有接口档留空
  -> 验证条件：V01 至 V09
  -> 回填位置：solution.md 第 1 节
```

## 3. 决策表

| 决策 | 选择 | 原因 | 备选路径 |
| --- | --- | --- | --- |
| 第一版指标范围 | CPU、内存、磁盘、网络、电池、合盖、热压力 | 全部无权限，全部有本机证据 | 加 GPU 与蓝牙 |
| GPU 使用率 | 第一版纳入 | `IOAccelerator` 是公开服务，本机有键 | 后续再加 |
| 温度与风扇 | 留接口，不实现 | SMC 键随 SoC 变，本机未验证 | 用 SMC 键表 |
| CPU 频率 | 不做 | `IOReport` 本机不可解析 | 用 IOReport |
| Wi-Fi 名称 | 不申请位置服务 | 隐私成本高于显示价值 | 申请位置服务 |
| 蓝牙设备 | 第二版做 | 需要蓝牙授权弹窗 | 第一版就做 |
| 刷新方式 | 速率值轮询，状态值推送 | 推送省电，轮询简单 | 全部轮询 |
| 电池供电时的周期 | 拉长到 5 秒 | 控制续航影响 | 不区分供电 |
| 公网地址 | 默认关 | 有隐私影响 | 默认开 |

## 4. 不采用方案

| 方案 | 风险 | 不采用原因 |
| --- | --- | --- |
| 用 IOReport 取频率与功耗 | 本机已不可解析，随系统升级失效 | 第一版不承担这个风险 |
| 常驻 1 秒轮询全部指标 | 影响续航 | 只在监控页可见时采样 |
| 用 `system_profiler` 取常规指标 | 每次要起进程，输出格式会变 | 只用于低频的机型与配件信息 |
| 用 `top` 与 `ps` 取进程列表 | 要解析文本输出 | 优先用 `libproc` |
| 第一版就申请位置服务 | 用户可能拒绝，且弹窗影响体验 | 信号强度不需要授权，先做信号 |
| 把台式机与笔记本合并处理 | 台式机没有电池与合盖 | 按能力探测，不按机型写死 |

## 5. 限制和未决项

### 5.1 系统限制

1. 私有接口没有文档，也没有兼容性承诺。
2. SMC 键名按 SoC 变化。
3. Wi-Fi 名称受位置服务控制。
4. 台式机没有电池与合盖状态。

### 5.2 产品限制

1. 第一版不显示温度、风扇和频率。
2. 第一版不显示蓝牙设备电量。
3. 采样只在监控页可见时进行。

### 5.3 未决项

| 项目 | 现状 | 下一步 |
| --- | --- | --- |
| IOReport 在 macOS 26 与 27 的可用路径 | 本机不可解析 | 开 spike，时间盒 3 个工作日 |
| SMC 读取是否真的无需 root | 只有源码证据 | 案例 V08，需要先有 SMC 读取工具 |
| 采样开销 | 未实测 | 补一项测试 |
| 环境光与亮度 | 未调研 | 单独调研 |
| Intel 机型差异 | 未验证 | 找 Intel 机器 |
| Windows 全部 | 占位 | 展开 investigation 第 9 节 |

## 6. 已决项

| 项目 | 结论 |
| --- | --- |
| 第一版是否需要 root | 不需要 |
| 第一版是否需要私有接口 | 不需要 |
| 是否需要特权 helper | 不需要。写风扇才需要。 |
| 是否申请位置服务 | 第一版不申请 |
