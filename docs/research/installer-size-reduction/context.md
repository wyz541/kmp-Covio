# 问题与边界

## 文档状态

| 项目 | 内容 |
| --- | --- |
| 状态 | 可评审 |
| 日期 | `2026-10-24` |
| 问题类别 | 大型本地模型应用的发布包体积控制 |
| 决策目标 | 选择 Covio 的全局最优模型交付方式 |

## 研究问题

在保留 Covio 现有离线能力、安装与升级可靠性的前提下，Covio macOS 安装包应采用哪种全局最优的体积缩减方案？

## 问题定义

当前 DMG 把一个约 `1.8 GB` 的模型和约 `35 MB` 的 app 放在一起。
模型的固定文件大小决定 DMG 下限。
只优化代码、资源或 DMG 压缩无法消除包体问题。
因此，问题实际是模型应在何时、以何种包交付。

## 触发条件

1. 用户下载 `Covio 0.5.2` 时看到 `1.54 GB` DMG。
2. 模型没有随每次 app 代码变化而变化。
3. GitHub 单文件发布能力不适合所有模型档位。
4. 用户需要可恢复、可校验的安装体验。

## 问题分类

| 类别 | 是否适用 | 原因 |
| --- | --- | --- |
| 模型分发 | 是 | 模型是主要体积来源 |
| 安装包压缩 | 是，但收益有限 | 高熵量化权重难以进一步压缩 |
| 代码裁剪 | 是，但收益有限 | 非模型内容仅约 `34.7 MB` |
| 更新差分 | 是，但不解决首次安装 | 差分只减少后续更新 |
| 模型质量 | 不作为本调研主变量 | 本调研不降级现有模型能力 |
| 云推理 | 否 | 违反本地处理和离线边界 |

## 适用范围

1. macOS 26 及后续版本。
2. Apple Silicon arm64。
3. SwiftUI 宿主和 `kmpDomain`。
4. 本地 MLX 模型和文件自动命名、Agent 功能。
5. 默认在线安装和可选离线安装。
6. `Developer ID` 与 notarization 后续路线。

## 范围外事项

1. 不重新评测模型准确率。
2. 不改变 ADR-0013 的硬件档位规则。
3. 不引入远程 AI 推理。
4. 不把用户文件上传到网络。
5. 不在本调研阶段提交产品代码。
6. 不决定 App Store 发布策略。
7. 不创建 Intel 或 Universal 2 构建。

## 受影响角色

| 角色 | 影响 |
| --- | --- |
| 首次安装用户 | 默认下载从约 `1.54 GB` 降到小于 `50 MB` |
| 离线环境用户 | 使用可选离线整包 |
| 已有用户 | app 更新不再重复包含模型 |
| 发布负责人 | 需要发布 app、模型和可选离线整包 |
| 测试人员 | 需要验证下载、恢复、校验和离线路径 |
| 安全评审人员 | 需要验证模型来源、哈希和许可证 |

## 系统模型

| 组件 | 职责 |
| --- | --- |
| 发布脚本 | 生成默认 DMG 和可选离线整包 |
| SwiftUI app | 管理模型状态、用户同意和错误提示 |
| Model manager | 下载、暂停、恢复、校验和激活模型 |
| Hugging Face Hub | 提供固定 revision 的模型文件 |
| Model verifier | 校验 revision、大小、SHA-256 和许可证 |
| Application Support | 保存模型和导入注册表 |
| MLX runtime | 从本地模型目录加载模型 |
| GitHub Releases | 发布 app、校验和和可选的离线整包 |

## 状态矩阵

| 状态 | 触发条件 | 模型 | 网络 | AI 功能 |
| --- | --- | --- | --- | --- |
| `not_installed` | 首次启动或模型缺失 | 不存在 | 可用或不可用 | 显示安装入口 |
| `downloading` | 用户确认下载 | 临时目录 | 可用 | 显示进度和暂停 |
| `verifying` | 下载完成 | 临时目录 | 不要求 | 显示校验状态 |
| `ready` | 校验和原子提交完成 | 正式目录 | 不要求 | 可用 |
| `paused` | 用户暂停或网络中断 | 临时目录 | 不要求 | 显示恢复入口 |
| `failed` | 下载、校验或磁盘失败 | 临时目录或不存在 | 视错误而定 | 显示错误和重试 |
| `unsupported` | 内存不足或模型 revision 不支持 | 可以是正式目录 | 不要求 | 拒绝加载并说明原因 |
| `offline_bundle` | 用户安装可选整包 | 正式目录 | 不要求 | 可用 |

## 场景定义

### 场景 1：默认在线安装

用户下载瘦 DMG。
用户安装并启动 app。
用户打开 AI 功能。
app 说明模型大小和用途。
用户确认下载。
app 完成恢复和校验。
用户断网后仍可使用 AI 功能。

### 场景 2：完全离线安装

用户下载可选离线整包。
用户在无网络环境安装 app 和模型。
app 首次启动时直接发现本地模型。
app 不访问网络。

### 场景 3：模型下载失败

下载中断后，app 保留临时文件或清理无效文件。
app 不把未完成目录注册为可用模型。
用户恢复网络后继续下载。

### 场景 4：app 更新

app 更新后继续使用相同 revision 的模型。
更新过程不删除模型。
只有模型 revision 变化时，app 才请求新的模型包。

### 场景 5：模型损坏

文件大小或 SHA-256 不匹配。
app 拒绝加载模型。
app 保留原有可用模型或显示重新下载入口。

## 成功标准

1. 默认 DMG 不大于 `50 MB`。
2. 无模型时 app 可以启动。
3. 下载中断后可以恢复。
4. 损坏模型不能被加载。
5. 模型就绪后断网可用。
6. app 更新不重下未变化的模型。
7. 可选离线整包可在断网环境完成安装。
8. 所有模型文件有固定 revision 和 SHA-256。
9. 发布包大小、签名和校验和可复核。
