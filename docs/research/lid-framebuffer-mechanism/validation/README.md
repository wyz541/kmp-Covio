# 验证总表

## 1. 目标

验证以下三个条件能否同时成立：

1. 系统保持 awake。
2. 内建屏逻辑上 online、active、未 asleep。
3. 捕获工具取得非空画面。

同时验证物理面板亮度为 `0.0` 或接近 `0.0`。

## 2. 范围

| 场景 | 是否验证 |
| --- | --- |
| 开盖 active 基线 | 已验证 |
| 合盖黑屏捕获 | 待执行 |
| 合盖关屏对照 | 待执行 |
| 外接屏组合 | 待执行 |
| 锁屏 | 待执行 |
| DRM | 待执行 |
| 崩溃恢复 | 已在前序矩阵验证 |
| macOS 26 | 待执行 |

## 3. 状态矩阵

| 场景 | SleepDisabled | online | active | asleep | brightness | capture |
| --- | --- | --- | --- | --- | --- | --- |
| 开盖基线 | 0 或 1 | 1 | 1 | 0 | > 0 | 非空 |
| 合盖黑屏 | 1 | 1 | 1 | 0 | 0.0 | 待测 |
| 合盖关屏 | 1 | 1 或 0 | 0 | 1 | 0 或驱动值 | 空白或失败 |
| 外接屏 | 1 | 外接屏 1 | 外接屏 1 | 内建屏可变 | 分开读取 | 独立判断 |

## 4. 运行顺序

1. 记录开盖亮度。
2. 记录开盖截图。
3. 开启实验性合盖黑屏。
4. 启动会话。
5. 合上上盖。
6. 记录 online、active、asleep。
7. 记录亮度。
8. 运行 ScreenCaptureKit 截图。
9. 运行 `screencapture` 对照。
10. 运行 Computer Use 截图。
11. 打开上盖。
12. 恢复亮度并释放租约。
13. 检查 `SleepDisabled=0`。
14. 检查 `sleep_owner` 不存在。

## 5. 验收标准

1. 合盖期间系统不睡眠。
2. 内建屏 online 为 `1`。
3. 内建屏 active 为 `1`。
4. 内建屏 asleep 为 `0`。
5. 亮度回读接近 `0.0`。
6. 至少一个捕获 API 返回非空图像。
7. 图像包含可识别内容。
8. 捕获失败有明确错误，不伪造成功。
9. 开盖后亮度恢复。
10. 系统电源状态恢复。

## 6. 风险

1. 合盖会阻断屏幕观察。
2. 私有亮度失败可能短暂留下黑屏。
3. 截图可能包含隐私数据。
4. 锁屏和 DRM 会产生误判。
5. 外接屏可能改变主显示器。
6. 强制中断可能留下亮度记录。

## 7. 清理

1. 结束会话。
2. 恢复亮度。
3. 释放 helper 租约。
4. 确认 `SleepDisabled=0`。
5. 确认 `sleep_owner` 不存在。
6. 删除临时截图。
7. 不把截图提交到仓库。

## 8. 回归

1. macOS 更新后重跑。
2. 修改屏幕捕获代码后重跑。
3. 修改 helper 协议后重跑。
4. 修改亮度恢复逻辑后重跑。
