# 离线本地服务 Agent：结论

## 结论摘要

条件性 go。
Agent 可以作为导航级功能上线。
模型只负责提出工具调用。
registry 负责最终校验和执行。

## 主要决策因素

1. 30 个请求中 27 个工具选择正确。
2. 未授权副作用为 0。
3. 恶意 shell、路径和网络请求没有执行。
4. `mlx-swift-lm` 已提供工具 schema、严格校验和工具调用恢复。
5. 现有运行时可以直接提供服务数据。
6. 7 GB Apple Silicon 安装包验收通过。

## 次要决策因素

1. 进程内调用不需要端口和 daemon。
2. 副作用确认可以在 UI 中实现。
3. 服务结果可以脱敏后作为 JSON 返回。
4. 测试可以注入 fake handler。
5. 验收环境低于 8 GB 产品门槛。

## 根因证据链

```text
模型会生成工具调用
  -> 调用格式可能错误
  -> 参数可能不正确
  -> 模型不能拥有执行权
  -> registry 必须再校验
  -> 副作用必须确认
```

## 决策表

| 决策 | 结果 |
| --- | --- |
| 运行时 | 进程内 typed registry |
| 模型 | `Qwen3-VL-2B-Instruct-4bit` |
| 工具来源 | Covio 内置 allowlist |
| 自动执行 | 只读工具 |
| 副作用 | pending call + 用户确认 |
| 外部服务 | MCP loopback，ADR-0015；实施 #249 |
| 失败策略 | 停止本轮，不猜测 |

## 不采用方案

### 模型直接执行

模型准确率不足，并且参数可能错误。
未授权操作风险不可接受。

### 无认证的本机 HTTP

进程内 Agent 不需要额外端口。
通用 HTTP 会扩大认证、生命周期和攻击面。
外部服务改用带认证的 loopback MCP，见 [external-protocol.md](external-protocol.md)。

### 通用 Unix socket

现有 helper socket 只服务固定 `pmset` 白名单。
把它扩成通用 RPC 会扩大 root helper 攻击面。

## 系统限制

1. 工具选择准确率未达到 95%。
2. 模型可能生成 malformed syntax。
3. 多轮长期上下文未验证。

1. 首版只提供六个服务。
2. 不提供任意文件操作。
3. 不提供任意系统设置。
4. 需要用户逐次确认副作用。
