# Case 2：服务协议和权限边界

| 项目 | 内容 |
| --- | --- |
| 状态 | 通过 |
| 日期 | 2026-10-21 |

## 目标

选择本地 Agent 的服务协议和权限模型。

## 比较

| 方案 | 信任边界 | 安装成本 | 安全风险 | 结果 |
| --- | --- | --- | --- | --- |
| 进程内 registry | 主应用 | 无 | 低 | 采用 |
| Unix socket | 同用户进程 | 中 | 中 | 仅 helper |
| 本机 HTTP | 本机端口 | 高 | 高 | 不采用 |
| MCP | 外部进程 | 高 | 中 | 后续适配 |

## 权限结果

1. 只读工具自动执行。
2. `copy_text` 进入 pending。
3. 用户确认后执行一次。
4. 用户取消后不执行。
5. 非法工具名和参数拒绝。

## 结论

首版采用进程内 typed registry。  
MCP 保留为未来外部服务适配器。  
不修改 privileged helper 的固定命令白名单。
