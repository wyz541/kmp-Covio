# 结论

## 1. 结论

Covio 应把 `automatic` 明确定义为系统自动。
系统自动模式只释放风扇控制，不持有风扇，不写目标转速。
多点曲线应使用独立的 `curve` 模式。
手动模式应提供默认关闭的同步开关。

## 2. 依据

Stats 的自动回调写模式 `0`（`E-01`）。
Stats 的 Apple Silicon 自动路径清除目标值（`E-03`）。
Stats 的同步滑杆按百分比换算（`E-04`）。
Stats 的同步默认关闭（`E-06`）。
历史修复说明绝对 RPM 不适合不同范围（`E-07`）。

## 3. 取舍

| 方案 | 结果 |
| --- | --- |
| 保持现有自动曲线 | 继续覆盖系统热管理，不采用 |
| 自动模式交还系统 | 与 Stats 一致，采用 |
| 删除曲线功能 | 丢失已评审能力，不采用 |
| 曲线作为显式模式 | 保留能力并区分控制者，采用 |
| 绝对 RPM 同步 | 不同风扇速度位置不一致，不采用 |
| 百分比同步 | 适配每台风扇范围，采用 |

## 4. 限制

本次调研不包含真机写入验证。
结论只覆盖源码展示的控制语义。
模式 `3` 的系统行为仍依赖 macOS 实现。
