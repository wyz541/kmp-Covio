# 上下文

## 问题

Covio 的自动曲线以手动风扇模式运行。
Covio 每秒写入目标转速。
Stats 的自动模式让系统热管理继续控制风扇。

问题是 Covio 应采用哪一种自动模式语义。

## 范围

- Stats 当前的自动、手动、睡眠和恢复行为。
- Stats 的同步控制开关。
- Stats 的 Apple Silicon 模式值。
- Covio 的模式模型、持久化和 UI。

## 范围外

- 风扇硬件写入验证。
- Stats 的安装流程。
- Stats 的传感器名称库。
- 三个以上风扇的硬件矩阵。

## 角色

| 角色 | 责任 |
| --- | --- |
| Covio 用户 | 选择系统自动、曲线或手动控制 |
| Covio 应用 | 保存配置并申请 helper 租约 |
| Covio helper | 持有风扇或恢复系统控制 |
| macOS 热管理 | 在系统自动模式控制风扇 |

## 关键约束

- 自动模式不能继续写 `F%dTg`。
- 手动写入必须限制在每台风扇的 `Mn` 和 `Mx` 之间。
- 同步控制必须处理不同风扇的硬件范围。
- 关闭同步后，各风扇保留独立转速。
- 配置必须跨启动保存。
