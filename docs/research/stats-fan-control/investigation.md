# 调研

## 1. Stats 控制路径

```text
FanView
  -> ModeButtons
  -> SMCHelper
  -> SMC.setFanMode / setFanSpeed
  -> F%dMd / F%dTg
```

Stats 不运行单独的温控守护进程。
Stats 的自动模式调用系统模式。
Stats 的手动模式由应用保存自定义转速。

## 2. 模式

| Stats 模式 | SMC 值 | 控制者 | Covio 对应概念 |
| --- | --- | --- | --- |
| Automatic | `0` | macOS | 系统自动 |
| Auto3 | `3` | macOS | 系统自动 |
| Manual | `1` | Stats | 手动转速 |

Stats 没有多点温控曲线的模式值。
Covio 的曲线必须保留为显式 `curve` 模式。

## 3. 同步

同步开关默认关闭。
滑杆变化按百分比发送。
每台目标风扇使用自己的 `Mn` 和 `Mx` 计算 RPM。
模式、最低、最高、全速和关闭也同步。
同步事件带抑制标记，避免再次广播。

## 4. 睡眠

Stats 在睡眠前把自定义手动风扇切回自动。
Stats 在唤醒 3 秒后恢复自定义模式和转速。
该行为只对自定义手动模式生效。

## 5. 风险

- 模式 `3` 容易被误判为手动模式。
- 不同风扇的范围不同，不能复制绝对 RPM。
- 同步事件缺少抑制会产生递归广播。
- 自动模式继续写目标值会覆盖系统热管理。

## 6. Covio 差距

Covio 把自动曲线实现为持续手动写入。
Covio 没有持久化同步开关。
Covio 的手动滑杆只写当前风扇。
Covio 的记录恢复逻辑会写回原模式，但 UI 没有区分系统自动和曲线。
