# Windows 宿主验证计划

## 1. 目标

验证 Windows CMP 宿主能编译、打包、启动、常驻托盘并保存用户配置。

## 2. 范围

覆盖 Windows 构建、应用镜像、MSI、托盘、单实例、登录启动和高 DPI。跨设备网络不在本计划内。

## 3. 环境

| 项目 | 要求 |
| --- | --- |
| Windows | Windows 11 24H2 或更高 |
| 账户 | 标准用户和本地管理员各一个 |
| JDK | 25 |
| Amper | 0.12.1 |
| WiX | `jpackage` 所需版本 |
| 显示器 | 至少一台；最好包含不同缩放比例的显示器 |

## 4. 测试矩阵

| ID | 测试 | 成功标准 | 状态 |
| --- | --- | --- | --- |
| V01 | Windows 编译 | `kotlin.bat build -m windowsProbe` 通过 | Windows CI 通过 |
| V02 | Windows 测试 | 宿主测试通过，并记录全量共享测试结果 | 宿主通过；全量未通过 |
| V03 | 可执行 JAR | 生成 JAR 并可启动 | CI 已生成；启动待测 |
| V04 | app-image | `jpackage --type app-image` 成功 | CI 已通过 |
| V05 | MSI | `jpackage --type msi` 成功 | CI 已通过 |
| V06 | 托盘 | 菜单、双击和退出可用 | 待执行 |
| V07 | 单实例 | 第二实例唤醒第一个实例 | 待执行 |
| V08 | 登录启动 | 开启创建启动项，关闭删除启动项 | 待执行 |
| V09 | 高 DPI | 100%、125%、150% 无裁切 | 待执行 |
| V10 | 多显示器 | 窗口移动后保持可见 | 待执行 |

## 5. 风险

| 风险 | 影响 | 降低办法 |
| --- | --- | --- |
| 无 Windows 真机 | 托盘和发行不可确认 | 使用标准 Windows 11 测试机 |
| MSI 工具缺失 | 无法生成安装包 | CI 安装 WiX |
| 代码签名缺失 | SmartScreen 警告 | 内测使用 SHA-256 清单并说明风险 |
| 会话结束 | 托盘进程退出 | 明确在线状态和启动行为 |
| 配置目录错误 | 用户数据写到错误位置 | 在标准账户下核对路径 |

## 6. 清理

1. 卸载测试 MSI。
2. 删除测试启动项。
3. 删除测试用户配置。
4. 恢复显示缩放设置。
5. 记录清理时间和结果。

## 7. 通过规则

1. V01 到 V05 必须通过。
2. V06 到 V12 至少有一台 Windows 11 真机记录。
3. 未通过项写明原因、影响人和后续动作。
4. CI 通过不能代替 V06 到 V10。
