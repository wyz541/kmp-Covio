Covio 的主循环从一个入口开始，经过一个工作区，最后用可见状态结束。

<div class="product-flow guide-flow">
  <article>
    <span>01</span>
    <h3>从菜单栏进入</h3>
    <p>用户点击状态项或让指针进入品牌胶囊。</p>
    <a href="/components/tray-icon/">菜单栏图标</a>
  </article>
  <article>
    <span>02</span>
    <h3>选择工作区</h3>
    <p>用户从首页组件卡或页签进入任务区域。</p>
    <a href="/components/">组件图鉴</a>
  </article>
  <article>
    <span>03</span>
    <h3>处理内容</h3>
    <p>文件、截图、剪贴板或设备状态在对应区域处理。</p>
    <a href="/components/screenshot-card/">截图卡片</a>
  </article>
  <article>
    <span>04</span>
    <h3>执行操作</h3>
    <p>按钮、开关和菜单项把用户选择变成动作。</p>
    <a href="/components/button/">按钮</a>
  </article>
  <article>
    <span>05</span>
    <h3>确认结果</h3>
    <p>卡片、提示和状态文字说明动作是否完成。</p>
    <a href="/chapters/interface-map/">界面地图</a>
  </article>
</div>

## 流程不是页面顺序

组件可以跨多个流程复用。流程负责说明关系和时机，组件页负责说明单个单元的行为。
