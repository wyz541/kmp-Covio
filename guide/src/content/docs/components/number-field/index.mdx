## 使用边界

数字输入接收短数值。时间、百分比和范围由调用方解释。

组件只检查整数格式。调用方要检查最小值、最大值、步长和单位。

## 状态

| 状态 | 界面表现 | 行为 |
| --- | --- | --- |
| 默认 | 系统圆角边框 | 用户可以直接输入 |
| 聚焦 | 系统焦点环 | 键盘输入进入此字段 |
| 错误 | 红色边框 | 当前文本不是整数 |
| 禁用 | 系统降低对比度 | 用户不能编辑 |

## 已知限制

- 当前错误样式只改变边框颜色，没有内联错误文字。调用方必须补充错误说明。
- 组件不检查数值范围。调用方要在写回配置前完成范围校验。
- 本轮截图没有覆盖键盘聚焦和完整 VoiceOver 流程。
