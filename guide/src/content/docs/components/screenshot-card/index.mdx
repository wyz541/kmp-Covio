## 它出现在哪里

截图卡片挂在晾衣线上。多张卡片共用一根绳子，并用夹子定位。

## 常用动作

| 操作 | 结果 |
| --- | --- |
| 单击 | 复制截图文件 |
| 双击 | 打开预览 |
| 长按 | 进入标注 |
| 拖拽 | 把文件交给其它应用 |
| 右键 | 保存、预览、标注或移除 |

## 已知限制

- 设计合同写的是 150 × 200 点。当前 `ShelfLayout` 生成 144 × 112 点的卡片。
- 合同列出选中和禁用状态。当前 SwiftUI 卡片没有独立实现这两个视觉变体。
- 键盘焦点和完整 VoiceOver 操作链仍需专项验收。
