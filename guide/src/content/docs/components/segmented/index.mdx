## 使用边界

分段控件适合二到五个短选项。选项较长或数量较多时，应使用菜单或列表。

用户选择后，调用方立即更新设置。需要确认的修改不应使用分段控件。

## 状态

| 状态 | 界面表现 | 行为 |
| --- | --- | --- |
| 默认 | 未选中段使用底色 | 控件可操作 |
| 悬停 | 系统悬停反馈 | 指针指出可操作段 |
| 已选 | 选中段使用独立底色 | 当前值唯一 |
| 聚焦 | 系统焦点环 | 键盘可以移动选择 |
| 禁用 | 系统降低对比度 | 用户不能改变选择 |

## 已知限制

- 合同要求选项超过三项时横向滚动。当前实现只设置最小宽度，没有额外滚动容器。
- 原生分段控件可能压缩长选项。调用方要限制选项数量和文字长度。
- 本轮截图没有覆盖键盘聚焦和完整 VoiceOver 流程。
