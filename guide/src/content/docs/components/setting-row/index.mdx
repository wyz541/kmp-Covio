## 使用边界

设置行负责排列信息。开关、数字输入和分段控件负责处理输入。

一行只放一个设置。需要多个独立动作时，应拆成多行。

## 状态

| 状态 | 界面表现 | 行为 |
| --- | --- | --- |
| 默认 | 标题、说明和控件对齐 | 控件可操作 |
| 悬停 | 合同定义悬停反馈 | 当前实现没有行级悬停样式 |
| 聚焦 | 合同定义焦点状态 | 焦点由右侧控件表达 |
| 禁用 | 合同定义降低对比度 | 调用方需要禁用右侧控件 |

## 已知限制

- 合同行高是 52 点。当前实现给内容区域设置 44 点最小高度，外层卡片提供周围留白。
- 当前布局没有整行点击手势。用户需要点击右侧控件。
- 行本身没有悬停、聚焦和禁用样式。调用方要禁用内部控件并检查视觉结果。
