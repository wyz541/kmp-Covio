## 使用边界

开关只表示二元状态。三个以上互斥选项应使用分段控件。

用户操作开关后，设置立即生效。需要保存按钮的操作不应使用开关。

## 状态

| 状态 | 界面表现 | 行为 |
| --- | --- | --- |
| 关闭 | 滑块在左 | 当前设置关闭 |
| 开启 | 滑块在右 | 当前设置开启 |
| 聚焦 | 系统焦点环 | 键盘可以继续操作 |
| 禁用 | 系统降低对比度 | 用户不能改变设置 |

## 已知限制

- 合同记录开关宽度为 38 点。`MacSwitch` 没有显式设置宽度，系统小尺寸样式决定实际边界。
- 本轮截图覆盖关闭、开启和禁用。键盘聚焦和完整 VoiceOver 流程尚未人工验收。
