## 两种入口

- 菜单栏浮层是主要入口。它显示玻璃吊卡图标。
- 系统状态项是兜底入口。图标使用同一份光栅缓存。

## 交互

左键切换 Hub。右键打开菜单。菜单提供「文件 → 截图」入口、设置和退出。
